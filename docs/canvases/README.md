# Archived Cursor canvases

Files here are **snapshots** of Cursor IDE canvases (``.canvas.tsx``) saved from
agent sessions. They import ``cursor/canvas`` and are meant to be opened in
Cursor beside a chat — they are **not** part of the ``dat-review`` runtime or
PyInstaller build.

Treat them as historical analysis artifacts (metrics, diagnosis narrative).
When numbers disagree with [PLAN.md](../../PLAN.md) or
[baseline_a.md](../baseline_a.md), trust the repo docs and current calibration
runs.
